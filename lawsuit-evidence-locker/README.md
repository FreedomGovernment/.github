# FreeLawGen — Evidence Locker & Legal Document Generator

> **Open-source legal document and campaign generator platform for legal activism and class action lawsuits.**

A Jekyll-based static website hosted on GitHub Pages — providing free, private, and professional legal tools for everyone.

## 🎯 Mission

FreeLawGen provides equal access to the legal system through open-source technology. No server costs, no monthly fees, no subscriptions — just professional legal tools that work.

## ✨ Features

- **📁 Evidence Locker** — Organize and track all your case evidence, documents, and timelines
- **📝 Document Converter** — Convert notes, scanned documents, and handwritten materials into clean markdown
- **🤖 AI Legal Assistant** — Integrate with OpenAI, Anthropic, or local LLMs to generate legal documents
- **📋 Legal Templates** — Professional templates for complaints, petitions, motions, briefs, timelines, and evidence logs
- **🔒 Privacy-First** — All data stored locally in your browser. No servers, no tracking, no cost.
- **💰 100% Free** — Hosted on GitHub Pages with zero hosting costs

## 🚀 Quick Start

1. **Visit the site** — Navigate to the FreeLawGen homepage
2. **Organize evidence** — Use the Evidence Locker to track your case materials
3. **Convert documents** — Format your notes and evidence into clean markdown
4. **Generate documents** — Use AI to create professional legal documents from templates
5. **Download & file** — Export your finished documents for filing

## 🛠️ Technology Stack

- **Static Site Generator:** Jekyll (GitHub Pages compatible)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Hosting:** GitHub Pages (free)
- **AI Integration:** OpenAI API, Anthropic API, or custom endpoints
- **Data Storage:** Browser localStorage (no server-side storage)
- **MCP Server:** Consumes YAML frontmatter for context routing

## 📝 YAML Frontmatter Schema

Each Markdown page uses YAML frontmatter (modeled after GitHub Docs) for MCP server context routing:

| Field | Type | Required | Purpose |
|-------|------|----------|---------|
| `title` | String | Yes | Page title for rendering and navigation |
| `shortTitle` | String | No | Abbreviated title for breadcrumbs/nav |
| `intro` | String | No | Summary text rendered below the title |
| `type` | String | No | Article type: `overview`, `how_to`, `reference` |
| `permissions` | String | No | Permission statement |
| `product` | String | No | Product identifier (`FreeLawGen`) |
| `layout` | String | No | Layout template name (`default`) |
| `versions` | Object | No | Version scoping (`fpt: '*'`, `ghes: '*'`) |
| `children` | Array | No | Child page links (on index pages) |
| `featuredLinks` | Object | No | Featured links grouping |
| `showMiniToc` | Boolean | No | Enable autogenerated mini table of contents |

Example:

```yaml
---
title: Evidence Locker
shortTitle: Evidence Locker
intro: Organize and manage your legal case evidence and documents.
type: how_to
permissions: Public
product: FreeLawGen
layout: default
versions:
  fpt: '*'
  ghes: '*'
showMiniToc: true
---
```

## 🔧 Local Development

### Prerequisites

- Ruby 3.x
- Jekyll gem

### Setup

```bash
# Clone the repository
git clone https://github.com/FreedomGovernment/lawsuit-evidence-locker.git
cd lawsuit-evidence-locker

# Install Jekyll (if not already installed)
gem install jekyll bundler

# Start the development server
jekyll serve

# Or use Bundler (recommended)
bundle install
bundle exec jekyll serve
```

The site will be available at `http://localhost:4000`.

## 🌐 Deployment

This site is configured for automatic deployment to GitHub Pages:

1. Push to the `main` branch
2. GitHub Actions will automatically build and deploy the site
3. The site will be available at `https://<username>.github.io/lawsuit-evidence-locker`

### GitHub Pages Configuration

- **Source:** Root directory (`/`)
- **Build command:** `jekyll build`
- **Publish branch:** `main`

## 🤖 AI Integration

FreeLawGen integrates with major LLM providers for document generation:

### Supported Providers

- **OpenAI** — GPT-4o, GPT-4o Mini
- **Anthropic** — Claude 3 Haiku, Claude 3 Sonnet
- **Custom** — Any OpenAI-compatible API endpoint

### Using AI

1. Navigate to the Document Converter page
2. Enter your API key (stored locally in your browser)
3. Select your preferred model
4. Enter your prompt (e.g., "Draft a complaint for a breach of contract claim")
5. Click "Generate Response"

**Privacy Note:** Your API key is stored only in your browser's localStorage. No data is sent to our servers.

## 🔒 Privacy & Security

- All evidence and case data is stored locally in your browser
- API keys are stored in localStorage and never transmitted to servers
- AI requests go directly from your browser to the LLM provider
- No analytics, tracking, or telemetry is collected
- All code is open-source and auditable
